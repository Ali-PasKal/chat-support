# چت پشتیبانی (Chat Support)

افزونه‌ی ساده‌ی چت آنلاین برای وردپرس. یک دکمه‌ی گفتگو روی سایت می‌آید، بازدیدکننده پیام می‌فرستد،
و شما از پنل وردپرس — روی کامپیوتر یا گوشی — جواب می‌دهید.

بدون سرویس خارجی و بدون اشتراک ماهانه: همه‌ی پیام‌ها در دیتابیس خود سایت شما ذخیره می‌شوند.

## چه چیزی دارد

- **ویجت چت** روی همه‌ی صفحه‌های سایت، با رنگ و متن دلخواه شما
- **پنل گفتگوها** داخل پیشخوان وردپرس: فهرست گفتگوها، جستجو، پاسخ دادن، بستن و حذف
- **دسترسی با موبایل**: پنل برای صفحه‌ی کوچک طراحی شده و با مرورگر گوشی کار می‌کند
- **شمارنده‌ی پیام نخوانده** کنار منوی وردپرس + صدا و اعلان مرورگر برای پیام تازه
- **ادامه‌ی گفتگو**: بازدیدکننده صفحه را ببندد و برگردد، تاریخچه‌اش سر جایش است
- **فرم اختیاری پیش از چت** برای گرفتن نام و ایمیل
- **پاک‌سازی خودکار** گفتگوهای قدیمی (اختیاری)
- راست‌به‌چپ، فارسی، بدون jQuery و بدون هیچ وابستگی بیرونی

## نصب

**راه اول — از پیشخوان وردپرس**

۱. از GitHub روی `Code` → `Download ZIP` بزنید.
۲. در وردپرس: `افزونه‌ها` → `افزودن` → `بارگذاری افزونه` → فایل ZIP را انتخاب کنید.
۳. `نصب` و بعد `فعال‌سازی`.

**راه دوم — با FTP**

پوشه‌ی افزونه را در `wp-content/plugins/chat-support/` بگذارید و از فهرست افزونه‌ها فعالش کنید.

بعد از فعال‌سازی، دکمه‌ی چت خودکار روی سایت ظاهر می‌شود. برای تغییر رنگ و متن‌ها به
`چت پشتیبانی` → `تنظیمات` بروید.

## استفاده

### پاسخ دادن به مشتری‌ها

در پیشخوان وردپرس منوی **چت پشتیبانی** → **گفتگوها**. فهرست سمت راست، متن گفتگو سمت چپ.
عدد قرمز کنار منو یعنی پیام خوانده‌نشده دارید. صفحه هر چند ثانیه خودش به‌روز می‌شود؛ لازم نیست رفرش کنید.

- **Ctrl+Enter** پاسخ را می‌فرستد
- **بستن گفتگو** آن را از فهرست «باز» بیرون می‌برد (اگر مشتری دوباره پیام بدهد، خودکار باز می‌شود)
- **حذف** گفتگو و همه‌ی پیام‌هایش را برای همیشه پاک می‌کند

### دسترسی با گوشی

با مرورگر گوشی وارد پیشخوان وردپرس شوید:

```
https://your-site.com/wp-admin/admin.php?page=chat-support
```

برای اینکه مثل یک اپلیکیشن باز شود:

- **اندروید (کروم):** منوی سه‌نقطه ← «افزودن به صفحه اصلی»
- **آیفون (سافاری):** دکمه‌ی اشتراک‌گذاری ← «Add to Home Screen»

بعد از آن یک آیکون روی صفحه‌ی گوشی دارید که مستقیم پنل گفتگوها را باز می‌کند.

> اگر می‌خواهید حتی وقتی پنل باز نیست هم خبردار شوید، در همان صفحه وقتی مرورگر اجازه‌ی
> «اعلان» خواست، قبول کنید.

### دادن دسترسی به همکاران

به‌طور پیش‌فرض فقط مدیر کل سایت به گفتگوها دسترسی دارد. برای اینکه مثلاً نویسنده‌ها هم
بتوانند جواب بدهند، این را در `functions.php` قالب بگذارید:

```php
add_filter( 'chat_support_capability', function () {
	return 'edit_posts';
} );
```

## تنظیمات

| تنظیم | کارش چیست |
|---|---|
| وضعیت | روشن/خاموش کردن ویجت روی کل سایت |
| عنوان و زیرعنوان | متن بالای پنجره‌ی چت |
| پیام خوش‌آمد | اولین چیزی که بازدیدکننده می‌بیند (در دیتابیس ذخیره نمی‌شود) |
| نام پشتیبان | نامی که کنار پاسخ‌های شما نشان داده می‌شود |
| رنگ اصلی | رنگ دکمه و حباب پیام‌ها |
| جای دکمه | پایین راست یا پایین چپ |
| فرم پیش از چت | گرفتن نام و/یا ایمیل قبل از شروع گفتگو |
| صدای پیام جدید | پخش صدا در پنل هنگام رسیدن پیام |
| مدت نگهداری | حذف خودکار گفتگوهای قدیمی‌تر از N روز (صفر = هیچ‌وقت) |

## برای برنامه‌نویس‌ها

### قلاب‌ها (Hooks)

```php
// پنهان کردن ویجت در صفحه‌های خاص
add_filter( 'chat_support_show_widget', function ( $show ) {
	return is_page( 'checkout' ) ? false : $show;
} );

// اطلاع از پیام تازه‌ی بازدیدکننده — مثلاً ارسال ایمیل یا تلگرام
add_action( 'chat_support_visitor_message', function ( $message, $conversation ) {
	wp_mail( get_option( 'admin_email' ), 'پیام جدید چت', $message->message );
}, 10, 2 );

// اطلاع از پاسخ اپراتور
add_action( 'chat_support_admin_message', function ( $message, $conversation ) {}, 10, 2 );

// تغییر سقف طول پیام (پیش‌فرض ۲۰۰۰ نویسه)
add_filter( 'chat_support_max_message_length', fn() => 5000 );

// تغییر سقف تعداد پیام در دقیقه برای هر آی‌پی (پیش‌فرض ۲۰)
add_filter( 'chat_support_messages_per_minute', fn() => 10 );
```

### REST API

مسیرها زیر `/wp-json/chat-support/v1/` هستند:

| مسیر | متد | دسترسی | کار |
|---|---|---|---|
| `/session` | POST | عمومی | شروع یا ادامه‌ی گفتگو، برمی‌گرداند: توکن + تاریخچه |
| `/messages` | GET | عمومی (با توکن) | گرفتن پیام‌های تازه |
| `/message` | POST | عمومی (با توکن) | ارسال پیام بازدیدکننده |
| `/conversations` | GET | اپراتور | فهرست گفتگوها |
| `/conversations/{id}` | GET / DELETE | اپراتور | خواندن یا حذف گفتگو |
| `/conversations/{id}/reply` | POST | اپراتور | پاسخ دادن |
| `/conversations/{id}/status` | POST | اپراتور | بستن یا باز کردن |

مسیرهای اپراتور با **Application Password** وردپرس هم کار می‌کنند، پس اگر روزی خواستید
اپلیکیشن موبایل بنویسید، همین مسیرها کافی است:

```bash
curl -u "username:xxxx xxxx xxxx xxxx" \
  https://your-site.com/wp-json/chat-support/v1/conversations
```

### جدول‌های دیتابیس

- `{prefix}chat_support_conversations` — هر گفتگو یک ردیف
- `{prefix}chat_support_messages` — هر پیام یک ردیف

با حذف افزونه این جدول‌ها پاک **نمی‌شوند** تا تاریخچه از دست نرود. اگر خواستید کامل پاکشان کنید:

```sql
DROP TABLE wp_chat_support_messages, wp_chat_support_conversations;
```

(به‌جای `wp_` پیشوند جدول‌های سایت خودتان را بگذارید.)

## سوال‌های رایج

**پیام‌ها چطور می‌رسند؟ WebSocket لازم است؟**
نه. افزونه هر چند ثانیه از سرور می‌پرسد پیام تازه‌ای هست یا نه. این روش روی هاست‌های
اشتراکی ایرانی هم بدون تنظیمات اضافه کار می‌کند. وقتی پنجره‌ی چت باز است هر ۴ ثانیه و
وقتی بسته است هر ۲۵ ثانیه بررسی می‌شود.

**با افزونه‌های کش مشکلی ندارد؟**
نه. ویجت هیچ اطلاعات شخصی‌ای داخل صفحه چاپ نمی‌کند و گفتگو با یک توکن در
`localStorage` مرورگر دنبال می‌شود، پس صفحه‌ی کش‌شده هم درست کار می‌کند.

**چند نفر هم‌زمان می‌توانند جواب بدهند؟**
بله، هر کسی که دسترسی داشته باشد می‌تواند پنل را باز کند. همه یک صندوق مشترک می‌بینند.

**پیام‌ها امن هستند؟**
متن پیام‌ها به‌صورت متن ساده ذخیره و نمایش داده می‌شوند (هیچ HTML‌ای اجرا نمی‌شود)، همه‌ی
کوئری‌ها با `$wpdb->prepare` نوشته شده‌اند و برای جلوگیری از اسپم، هر آی‌پی در دقیقه
سقف تعداد پیام دارد.

**ویجت نمایش داده نمی‌شود.**
مطمئن شوید در تنظیمات روشن است و قالب سایتتان تابع `wp_footer()` را صدا می‌زند
(همه‌ی قالب‌های استاندارد این کار را می‌کنند).
