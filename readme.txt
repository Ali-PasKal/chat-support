چت آنلاین ساده برای وردپرس. ویجت گفتگو روی سایت و پنل پاسخ‌دهی که روی موبایل هم کار می‌کند.

== Description ==

افزونه‌ی چت آنلاین بدون سرویس خارجی. بازدیدکننده از روی سایت پیام می‌دهد و شما از پیشخوان
وردپرس — با کامپیوتر یا گوشی — جواب می‌دهید. همه‌ی پیام‌ها در دیتابیس خود سایت می‌مانند.

* ویجت چت با رنگ و متن دلخواه
* پنل گفتگوها با جستجو، بستن و حذف گفتگو
* طراحی مناسب موبایل برای پاسخ‌دهی در حال حرکت
* شمارنده‌ی پیام نخوانده، صدا و اعلان مرورگر
* فرم اختیاری نام و ایمیل پیش از چت
* حذف خودکار گفتگوهای قدیمی
* راست‌به‌چپ و فارسی، بدون jQuery

== Installation ==

1. پوشه‌ی افزونه را در `wp-content/plugins/` بگذارید یا فایل ZIP را از پیشخوان بارگذاری کنید.
2. افزونه را فعال کنید.
3. به `چت پشتیبانی` → `تنظیمات` بروید و رنگ و متن‌ها را تنظیم کنید.

== Frequently Asked Questions ==

= پیام‌ها چطور می‌رسند؟ =

با پولینگ ساده روی REST API وردپرس. نیازی به WebSocket یا سرور جداگانه نیست، پس روی
هاست‌های اشتراکی هم کار می‌کند.

= با افزونه‌های کش سازگار است؟ =

بله. ویجت هیچ داده‌ی شخصی‌ای داخل HTML صفحه چاپ نمی‌کند.

= چطور به همکارانم دسترسی بدهم؟ =

با فیلتر `chat_support_capability` می‌توانید دسترسی را به نقش دلخواه بدهید.
